# 🛒 Responsive Shopping Cart Web Application

## 📌 Project Overview

The **Responsive Shopping Cart Web Application** is a simple front-end web project developed using HTML, CSS, JavaScript, and Bootstrap. The main objective of this project is to create a responsive shopping interface that works across different screen sizes, including desktops, tablets, and mobile devices.

The application provides a product catalog, shopping cart interface, login page, and registration page with a clean and user-friendly design.

## ✨ Features

- **Product Catalog:** Displays products with images and an Add to Cart button.
- **Shopping Cart:** Shows cart items, product prices, and a checkout interface.
- **Login Page:** Provides email and password input fields.
- **Registration Page:** Collects username, email, password, confirm password, mobile number, and age.
- **Responsive Design:** Uses Bootstrap's grid system and components to adapt to different screen sizes.
- **Interactive Elements:** Includes basic JavaScript functionality for adding products to the cart and registration form validation integration.
- **Consistent UI:** Uses a light blue background, dark navigation header, and Bootstrap styling.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the HTML files, image folder, and any required JavaScript files are present.
4. Install the **Live Server** extension in VS Code if you have not already installed it.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. Your default browser will open the shopping catalog.
8. Use the navigation links to visit the Cart, Login, and Register pages.

Alternatively, you can open `index.html` directly in your web browser.
